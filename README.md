# Our Little Universe

A romantic digital keepsake website built with TanStack Start, React, TypeScript, and Tailwind CSS.

## Development

Install dependencies with `bun install` or `npm install`, then run `bun run dev` or `npm run dev`.

Run checks with `bun run test`, `bun run lint`, and `bun run build`.

## Personal content and privacy

Editable story content is in `src/content/universe.ts`. Photos can be placed in `public/photos/`; audio files should only be added if you have the right to use them. This repository is currently public, so do not add private photos, personal letters, credentials, or secrets unless you first make the repository private.
