# Our Little Universe

Edit all names, dates, captions, letter, quiz and promises in `src/content/universe.ts`.

- Photos: put files in `public/photos/` and set `src: "/photos/01.jpg"` in the `photos` array.
- Music: add a track you own to `public/audio/` and set `musicSrc`. It never autoplays.
- Voice note: set `voiceSrc`, or visitors can pick a local file on the page.
